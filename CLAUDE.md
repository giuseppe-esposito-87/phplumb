# PHPlumb agent notes

## Deferred work

Open a GitHub issue on `lussoluca/phplumb` for every deferred item when you defer it: review findings left unfixed, limitations accepted for now, and regressions found but not fixed. Close the issue when the change that fixes it lands.

Never leave deferred work only in a chat message or in a plan's ledger, which is deleted when the plan finishes.

Read the open issues (`gh issue list`) before writing a plan, and name the issues the plan picks up.
