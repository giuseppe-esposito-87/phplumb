# PHPlumb agent notes

## Deferred work

Record every deferred item in `docs/backlog.md`, in the same change that defers it: review findings left unfixed, limitations accepted for now, and regressions found but not fixed. Remove an item in the change that fixes it.

Never leave deferred work only in a chat message or in a plan's ledger, which is deleted when the plan finishes.

Read `docs/backlog.md` before writing a plan, and name the items the plan picks up.
