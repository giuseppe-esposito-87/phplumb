# Engine data

`builtins.txt` lists the names of PHP's built-in classes, functions and constants. The engine uses it to tell a missing name from one that PHP or an extension provides.

The names are extracted from [JetBrains phpstorm-stubs](https://github.com/JetBrains/phpstorm-stubs), Copyright JetBrains s.r.o., licensed under the [Apache License 2.0](https://www.apache.org/licenses/LICENSE-2.0). Only the names are kept; no stub code is included.
